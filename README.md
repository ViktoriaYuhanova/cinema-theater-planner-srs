# Планировщик походов в кино и театр

О проекте

«Планировщик походов в кино и театр» — приложение для просмотра афиши предстоящих мероприятий и формирования собственного списка желаемых к посещению событий.

Основные возможности

* Просмотр афиши.
* Просмотр подробной информации о мероприятиях.
* Добавление мероприятий в список желаемого.
* Просмотр списка желаемого.
* Удаление мероприятий из списка.
* Поиск мероприятий.
* Фильтрация мероприятий по типу и дате.
